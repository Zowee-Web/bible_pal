# Bible PAL Kid Safety Blocklist
# ================================
# This file contains patterns that are forbidden in kid-friendly content (ages 6-11).
# Used by both build-time quality gates and runtime safety scanner.
#
# Format:
# - One pattern per line
# - Case-insensitive matching
# - Lines starting with # are comments
# - Empty lines ignored
# - Patterns are regex-compatible
#
# Categories:
# 1. Profanity and vulgar language
# 2. Sexual content and innuendo
# 3. Graphic violence and gore
# 4. Self-harm and suicide
# 5. Hate speech and slurs
# 6. Substance abuse
#
# Maintenance:
# - Add patterns conservatively to avoid false positives
# - Test new patterns before committing
# - Document reason for addition in comments
# - Keep patterns specific enough to avoid legitimate Biblical content
#
# Last Updated: 2025-12-28
