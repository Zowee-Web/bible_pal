# LEGACY Prompt Templates

This directory contains **legacy minute-based prompt templates** that have been deprecated in favor of the new storyLength bucket system.

**DO NOT USE** these prompts for new content generation. They are retained for reference only.

## Active Prompts

Use `server/prompts/golden_trad_adult_short.prompt.txt` for bucket-based generation.

## Files in This Directory

| File | Original Purpose |
|------|------------------|
| `golden_trad_adult_5min.prompt.txt` | Golden prompt for 5-minute adult stories |
| `trad_adult_5min.prompt.txt` | Standard prompt for 5-minute adult stories |
| `parable_114_5min.txt` | Sample story content |
