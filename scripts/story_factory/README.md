# Story Factory — Traditional Bible PAL Generator (B2)

Generates one Traditional Bible PAL story with 3 length variants, 1 canonical reflection, 4 audio files, and metadata.

All story and reflection prose is generated by **OpenAI gpt-4.1** via the Responses API. This script generates no prose itself.

## Prerequisites

- Python 3.9+
- `.env` file at repo root with:
  - `OPENAI_API_KEY`
  - `ELEVENLABS_API_KEY`
  - One or more `VOICE_*` variables (e.g. `VOICE_JAMES_HUSKY=EkK5I93UQWFDigLMpZcX`)

### Note on `.env` inline comments

The `.env` loader strips inline comments **only** when `#` is preceded by whitespace. This safely handles lines like:

```
VOICE_JAMES_HUSKY=EkK5I93UQWFDigLMpZcX  # Wise elder — calm storyteller
```

without accidentally truncating keys or values that contain `#` in other contexts.

## Usage

```bash
# KJV (Classic) lane
python3 scripts/story_factory/generate_traditional_story.py \
  --story_id 803 \
  --anchor "Psalm 46" \
  --mood hopeful \
  --lane kjv \
  --voice_key VOICE_JAMES_HUSKY

# WEB (Modern) lane
python3 scripts/story_factory/generate_traditional_story.py \
  --story_id 804 \
  --anchor "Romans 8:28" \
  --mood grateful \
  --lane web \
  --voice_key VOICE_JAMES_HUSKY
```

Or use the wrapper:

```bash
./scripts/story_factory/run_one.sh --story_id 803 --anchor "Psalm 46" --mood hopeful --lane kjv --voice_key VOICE_JAMES_HUSKY
```

## Output

Creates `assets/stories/traditional/<story_id>/` with:

| File | Description |
|------|-------------|
| `story_<id>_traditional_<lane>_short.txt` | Short story (300–500 words) |
| `story_<id>_traditional_<lane>_full.txt` | Full story (501–900 words) |
| `story_<id>_traditional_<lane>_long.txt` | Long story (901–1500 words) |
| `reflection_<id>_traditional_<lane>.txt` | One canonical reflection (B2) |
| `audio_<id>_story_short.mp3` | Short story audio |
| `audio_<id>_story_full.mp3` | Full story audio |
| `audio_<id>_story_long.mp3` | Long story audio |
| `audio_<id>_reflection.mp3` | Reflection audio |
| `meta_<id>.json` | Metadata |

Also updates `used_scripture_anchors.json` at repo root.

## Safety

- Aborts if output directory already exists (no overwrites).
- Aborts if scripture anchor is already in the registry (no duplicates).
- Enforces strict word-count ranges per length bucket.
- On any failure after creating the output dir, cleans up by removing it.
