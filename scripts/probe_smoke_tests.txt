# Life Situation Tags v1 — probe regression fixtures
#
# Format: <query> | <expectation>
#
# Expectations:
#   MUST_INCLUDE:<id>[,<id>...]  — every listed storyId must appear in results
#   MUST_EXCLUDE:<id>[,<id>...]  — none of the listed storyIds may appear
#   NO_MATCH                     — the probe must return zero results
#
# These are deterministic regression checks against the Mode B keyword-overlap
# CLI. They are NOT proof of natural-language understanding. A passing suite
# means "retrieval behavior is unchanged since this fixture was last
# reviewed," not "the system understands these queries."
#
# Add new entries when you find a probe whose result should remain stable
# across future vocabulary changes. Write probes BEFORE running them — the
# probes you write blind are signal; the ones you write after seeing results
# are confirmation bias.
#
# Lines starting with '#' and blank lines are ignored.
